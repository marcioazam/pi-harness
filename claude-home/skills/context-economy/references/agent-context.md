# Agent context: orchestrator and subagents

Practices for the main thread and for workers. Evidence is listed at the end with its caveats.

- **Context rot.** Accuracy falls as input grows on every model tested, even on simple tasks. Keep the main thread lean: delegate sweeps, hand workers paths and `file:line` slices, read only what settles a decision.
- **Clear old tool output before summarizing.** Observation masking (old tool output replaced by placeholders, reasoning and actions kept, last ~10 turns in full) was 52% cheaper with +2.6% solve rate on SWE-bench Verified. Summarization lengthened trajectories ~15% and its calls rarely hit the cache. A hybrid (mask first, summarize late) was cheapest. Anthropic calls tool-result clearing the safest, lightest compaction. Here (pi): filter large output at the source (file under `/tmp`, then `tail`/`rg`/`head`), and auto-compaction at 250k tokens as the last resort (`compaction.modelOverrides` in `~/.pi/agent/settings.json`, generated by `~/.pi/agent/scripts/compaction-400k.py`, plus the safety net `~/.pi/agent/extensions/compact-at-400k.ts`, threshold `PI_COMPACT_AT`).
- **Structured checkpoints.** Summaries with explicit sections (intent, files touched, decisions, next steps) retained more than generic compression, and every method lost the artifact trail. Keep the file list and decisions in the task's `/docs` record, not only in a summary. Optimize tokens per task, not per request (see [checkpoints](checkpoints.md)).
- **Cache-stable prefix.** Cached input costs a tenth of uncached or less (5% on Opus 5.5 and Sonnet 5.5). Keep the prefix stable (no timestamps), context append-only, serialization deterministic, and the tool set fixed mid-session. In briefs, stable text first and the unit last.
- **Just-in-time retrieval.** Context files (AGENTS.md/CLAUDE.md) up front; files fetched by `rg`, `fd` and codegraph (`tool_search` first) when needed. Never paste whole files into briefs.
- **Handbacks.** Compact and structured: the swarm-worker handback is status, changed files, summary up to 600 characters, risks. Machine-edited state is JSON, not prose.
- **Focus by recitation.** Rewrite the `todo` list or plan checkpoint at milestones so the objective stays at the end of the context.
- **Subagent isolation.** A worker explores in its own context and returns only the condensed result. Parallelism pays only for independent units (see `graph-engineering`).

- [Claude Opus 5.5 model page](https://docs.anthropic.com/en/docs/models/opus-5-5) (via Keenable, 2026-11-11): cache reads 10% of base input, 5% on Opus 5.5 and Sonnet 5.5.
