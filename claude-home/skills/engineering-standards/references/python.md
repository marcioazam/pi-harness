# Python

Respect `pyproject.toml`, `requires-python`, and the locked environment. Prefer uv when the project uses it; keep dependency metadata and configuration in the project's declared source of truth.

Use precise types at public and external boundaries, validate untrusted data, keep exceptions specific and informative, and avoid broad `except` blocks. Prefer ruff, the repository's type checker, and pytest configuration when present. Test async, I/O, and error paths explicitly rather than relying on mocks that duplicate implementation details.

Current specifics: for FastAPI services, read the installed FastAPI and Pydantic versions and follow the project's lifecycle conventions. Scope database sessions and HTTP clients through dependencies or lifespan; bound outbound timeouts and pagination, keep blocking calls out of async routes, and release resources on cancellation. Distinguish omitted fields from explicit null in partial updates. Response schemas exclude internal auth fields and keep documented error semantics. Point dependency overrides at the actual callable, and test validation, authorization denial and transaction failure. FastAPI 0.148 to 0.162 changed request defaults: omitted-parameter defaults are not validated without `validate_default=True` and no longer count as set, JSON `null` differs from an omitted body value, and empty form strings, unselected files and omitted form booleans count as missing; since 0.132 a JSON body without a JSON `Content-Type` is rejected unless `strict_content_type=False` ([release notes](https://fastapi.tiangolo.com/release-notes/), read 2026-11-11). Retest form and partial-update behavior across such an upgrade.
