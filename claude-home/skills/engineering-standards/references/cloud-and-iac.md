# Cloud and infrastructure as code

Make IaC changes reviewable and least-privilege by default. Pin action and provider versions, separate plan from apply, avoid secrets in state or logs, scope credentials and network access narrowly, and preserve rollback or recovery instructions.

For Terraform and Kubernetes, validate formatting, static checks, and a plan/diff before applying. Treat remote state, production targets, deletion protection, public exposure, workload identity, and IAM changes as high-risk boundaries requiring explicit confirmation before mutation.

Current specifics (sources read 2026-10-24):

- Terraform and OpenTofu: detect the engine and keep its pin. Prefer `moved`, [`import`](https://developer.hashicorp.com/terraform/language/import) and [`removed`](https://developer.hashicorp.com/terraform/language/state/remove) blocks to state commands. Inspect drift with `plan -refresh-only`: [`refresh`](https://developer.hashicorp.com/terraform/cli/commands/refresh) is an auto-approved state write, and [`taint`](https://developer.hashicorp.com/terraform/cli/commands/taint) is deprecated in favor of `-replace`. [`terraform test`](https://developer.hashicorp.com/terraform/language/tests) creates real infrastructure unless every run uses `command = plan` or every provider is mocked (1.7+). [`show -json`](https://developer.hashicorp.com/terraform/cli/commands/show) prints sensitive values in plain text. The S3 backend locks with [`use_lockfile`](https://developer.hashicorp.com/terraform/language/backend/s3); `dynamodb_table` is deprecated. `sensitive = true` still writes the value to state and plan: pass secrets through `ephemeral` resources or variables into the provider's write-only `*_wo` argument with its `*_wo_version` (Terraform 1.11+, OpenTofu 1.11+; read 2026-10-26); where the provider has none, report the secret-in-state risk instead of adding the secret.
- Kubernetes: target a minor that https://kubernetes.io/releases/ lists as supported (1.35 to 1.37 on 2026-10-24). Use EndpointSlice, not core `Endpoints`; no Service `externalIPs` and no `gitRepo` volumes; Ingress NGINX was retired on 2026-03-24, so prefer Gateway API ([v1.36 release](https://kubernetes.io/blog/2026/04/22/kubernetes-v1-36-release/)); nodes run [cgroup v2](https://kubernetes.io/docs/concepts/architecture/cgroups/).
- Cloudflare Workers: new projects use Workers Static Assets, not Pages ([best practices](https://developers.cloudflare.com/workers/best-practices/workers-best-practices/)) or Workers Sites, configured in `wrangler.jsonc` ([configuration](https://developers.cloudflare.com/workers/wrangler/configuration/)). A URL that matches an asset skips the Worker unless `run_worker_first` covers it; set `not_found_handling` explicitly and never serve crawlable content in single-page-application mode, which answers unknown URLs with 200 ([static assets](https://developers.cloudflare.com/workers/static-assets/)). Generate binding types with [`wrangler types`](https://developers.cloudflare.com/workers/languages/typescript/). [Remote bindings](https://developers.cloudflare.com/workers/local-development/) touch real data and bill even in local development, and AI bindings always run remotely.
